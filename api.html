セルフホストAPI

自分の環境から、旅程を組む。

旅さきのNode.js APIをローカルで起動し、/v1/planから旅程を作れます。既定はローカル限定。公開APIとして提供するものではありません。

APIの仕様を見る端末版を見る

まずは自分の端末で。

旅さきのセルフホストAPIは、Node.jsのローカルサーバーです。初期状態では127.0.0.1だけで待ち受け、APIキーなしで自分の端末から呼べます。

起動

詳しい設定は セルフホスト説明書 を参照してください。

旅程を組む

新規連携では版付きの /v1/plan を使います。外部インターフェースとして公開する場合は、32文字以上のBearerトークンを設定してください。認証なしで127.0.0.1以外に公開する設定は推奨しません。

APIの入り口

方法・パス役割
POST /v1/plan希望から旅程を作る
GET /v1/health稼働状態とAPI版を確認
OPTIONS /v1/*許可したブラウザからのCORS確認

初期設定の安全策

  • 既定では127.0.0.1だけで待ち受ける
  • 外部向けに待ち受けるときは認証トークンを要求する
  • 入力サイズ・許可する項目・回数・同時実行数に上限を設ける
  • ブラウザからの利用は、明示したOriginだけを許可する
  • ログには希望文やAPI鍵を残さない設計
!

このAPIはセルフホスト用です。パブリックな共有APIではありません。インターネットに公開する前にTLS、トークン管理、プロキシ側のレート制限、監視、利用規約を整えてください。公開中のWorkerのAI中継と、このNode.js APIは別のものです。
