旅さき・端末とアプリで動くソフトウェア

旅程を、手元で組む。

登録も料金もいりません。データは手元に置いて動きます。

旅さき。行きたいことを一文で書けば、全国の観光地から行き先を選び、営業時間と定休日、駅や停留所のあいだの移動時間を一つずつ照らし合わせて、そのまま行ける1日にします。端末でも、携帯のアプリでも、同じエンジンが動きます。

旅さきは、書いた文から「どこで・いつ・何をしたいか」を読み取り、収録している観光地の営業時間・定休日・最終入場と、移動にかかる時間を照らし合わせて順番を決めます。帰りの時刻に間に合わない旅程は出しません。

できること。

端末版とアプリ版は、同じ旅程のエンジンと同じ収録データで動きます。

01

一文から旅程を組む

「温泉と海をゆっくり」のような文から、行き先と順番を決めます。出発地・日付・日数・移動手段も指定できます。

02

帰りの時刻を守る

最終入場・定休日・帰りの列車に間に合わない並びは出しません。

03

雨の日に組み直す

天気を見て、雨の時間を屋内の場所に入れ替えます（replan --weather-check）。

04

前もって歩いてみる

組んだ旅程を時刻どおりにたどって、遅れたときにどこが崩れるかを確かめます（simulate）。

05

好きな形で書き出す

Markdown・テキスト・JSON・iCalendar（.ics）。CalDAV のカレンダーへも書けます。

06

圏外でも組める

エンジンと収録データを手元に置くので、電波の届かない山の中でも基本の旅程は組めます。

使う人に合わせて、選べる。

電車やバスの調べかたと、AI の使いかたは、設定で選びます。

乗り換えの調べかた

  • 公開されている API（おすすめ） … 時刻表や経路の API を使って、実際の乗り換えを調べます。
  • 使わない … 外へ通信せず、距離から移動時間の目安を出します（端末版の既定）。
  • スクレイピング（おすすめしません・自己責任） … API の無い路線のために、ページを読みに行く設定も置きます。相手のサイトの利用規約に反することがあるので、既定では切ってあり、使う人が自分の責任で入れるものです。

AI は、手元のモデルで

文の読み取りには、旅さき向けに調整した Gemma 4（26B A4B・MoE）を使えるようにしています（準備中）。AI が使えないときも、収録データだけで旅程は組めます。このサイトの上では AI は動きません。

乗り換えの設定と手元のモデルは、いまアプリ版・端末版に入れているところです。入ったら、ここに使いかたを書きます。

観光地・駅・バス停のデータ。

旅さきが組むときに使う観光地・駅・バス停のデータは、旅さき自身で集めて手入れしています。これを API の形で配る準備をしています。

行き先を、読んでから決める。
