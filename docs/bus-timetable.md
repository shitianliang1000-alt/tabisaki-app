# 旅さきのバス時刻表（自前の時刻引き）

ls8h に入っていないバス事業者の GTFS-JP を、中継（Cloudflare Worker）の中で引くしくみです。
`POST /transit` の `provider: "bus"`（画面での名前は「旅さきのバス時刻表」）で、auto のときは
ls8h・Transitous と同時に聞き、早く着く候補を選びます（[transit-apis.md](transit-apis.md)）。

## なぜ OpenTripPlanner を本番に出さないか

| | 自前の時刻引き（これ） | OTP を本番に出す |
|---|---|---|
| 動く場所 | いまの Worker の中（追加の契約なし） | 常に動くサーバ（JVM。全国だとメモリ数 GB）を借りる |
| 費用・手間 | 0 円。データはデプロイに同梱 | 月数千円〜。サーバの面倒を見る人が要る |
| 探せる経路 | バス1本・1回乗り換え（同じ停留所か、同じ名前で 300m 以内） | 何回でも乗り換え・電車とバスの乗り継ぎ |
| 速さ | 1回 数 ms（CPU 10ms の無料枠に収まる） | 中央値 153ms（熊本で測定。[otp.md](otp.md)） |

足りないのは「バスの区間」なので、まずは追加費用の無い自前の時刻引きにしました。電車とバスを
1本の経路で乗り継ぐ精度が要るようになったら、OTP を VPS などに出して `OTP_URL` を入れます
（そのときは持ち主の契約が要ります）。

## データ

```sh
python3 tools/build_bus_timetable.py            # data/bus-feeds.json の全部を落として data/bus/ を作り直す
python3 tools/build_bus_timetable.py --only toyo # 1本だけ作り直す
```

* 一覧は `data/bus-feeds.json`。落としたものは `data/gtfs-bus/`（.gitignore 済み）に置き、
  2回目からは落とし直しません（新しい版を取るときは消してから走らせる）。
* 出力の `data/bus/` はリポジトリに入れます（約 3.5MB）。`tools/build_worker.sh` が
  `.site/__bus/` に写し、Worker は ASSETS から読みます。**`/__bus/` は外から開くと 404** です
  （`run_worker_first` に入れて、Worker が止めます）。
* 形: `index.json`（一覧・出典・有効期間）、`tiles/<y>_<x>.json`（0.02 度四方の停留所と、
  そこを通るパターン）、`<feed>/cal.json`（運行日）、`<feed>/stops.json`、`<feed>/p<n>.json`
  （停まる順と、同じ所要の便の出発時刻だけ。元の stop_times の 1/20 ほど）。
* 走らせると `credits.html` の印（`bus-timetable:start`〜`end`）の間を、いまの一覧で書き直します。
  `tests/bus.test.js` が、一覧の全部が credits.html にあるかを見ます。

**期限に注意。** 時刻表には有効期間があります（`index.json` の `end`）。期限の切れた時刻表は
build が止めます。ダイヤ改正（多くは 4 月・10 月）のあとは、`data/gtfs-bus/` を消して作り直します。

## ライセンスの決まり

* 入れるのは、出典を書けば再配布してよいものだけ（CC BY 4.0・CC0・公共交通オープンデータ基本ライセンス）。
* 「公共交通オープンデータチャレンジ限定」のライセンス（神奈川中央交通など）と非商用のものは入れません
  （`tools/test_gtfs_bus_timetable.py` が一覧を見張ります）。
* CC BY の表記は2か所に自動で付きます。`credits.html` の一覧と、答えの `attribution`
  （「時刻表: 両備バス（両備ホールディングス・Bus-Vision、CC BY 4.0） を加工」）。
* ライセンスの書きかたが「オープンデータとして公開」だけのもの（港区ちぃばす）は、
  条件を確かめるまで `skip` にしています。
* OTTOP（沖縄）の6社は、GTFS 一覧（嶋田さん）と Transitland で CC BY 4.0（表記必須）とされ、
  沖縄県も無償・二次利用可としています。OTTOP の規約本文はサイトが JavaScript だけで読めず、
  まだ一次で確かめていません。

  県営バスの公式時刻表（2026/4/1 現在の PDF）と一致。

## まだ入っていないもの

* **ODPT の配布（約 50 事業者）**: 京王・小田急・関東バス・西東京バス・都内のコミュニティバス、
  京都市バス・京都バス、群馬の各社、宇野バス・下電バスなど。鍵（`acl:consumerKey`）が要ります。
  [developer.odpt.org](https://developer.odpt.org/) で登録し、鍵を作業する機械の環境変数
  `ODPT_KEY` に入れてから、`data/bus-feeds.json` の `odpt.pending` を `feeds` に移して build します。
  鍵は中継やサイトには置きません（URL は `{ODPT_KEY}` と書き、build のときだけ差し込みます）。
  ライセンスは公共交通オープンデータ基本ライセンス（`"license": "公共交通オープンデータ基本ライセンス"`、
  `"publisher"` に事業者名、`"source": "公共交通オープンデータセンター"`）。
* 公開先が移って落とせなかったもの: 群馬バス（403）、鹿児島市交通局・仙台市交通局（404）、
  日本中央バス（404。ODPT 版で入れる）。
* 期限切れの版しか見つからなかったもの: 山梨交通・富士急（busmaps の 2025-03 版）、関越交通・
  北海道拓殖バスの事業者サイト版（ODPT 版で入れる）。

## 登録が要るもの（持ち主の手が要る）

* **公共交通データHUB（PTD-HS）**: 神戸市バス・関東自動車・岩手県北バス。HUB の利用申請 →
  審査 → API キー発行。キーが届いたら、規約（再配布・商用・表記）を読んでから一覧に足します。
* **OTTOP（琉球バス交通・那覇バス）**: いまの公開一覧には2社の時刻表が見当たりません。
  OTTOP（contact@ottop.org）に、2社の GTFS の配信予定と利用条件を問い合わせます。
