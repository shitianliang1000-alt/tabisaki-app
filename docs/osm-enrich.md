# OpenStreetMap からの補完（営業時間・電話・サイト・車いす）

収録（`kb/`）にある場所へ、OpenStreetMap（OSM）に書かれている営業時間・電話・公式サイト・
車いすの可否・料金の有無を足します（Issue #423）。

**Overpass API は使いません。** 4万件ぶん聞くとレート制限に当たり、IP ごと止められます。
日本全体の配布ファイル（PBF）を手元で1回読めば、何件でも突き合わせられます。

## 走らせかた

```bash
pip install osmium                       # 配布ファイルを読む部品（pyosmium）
python3 tools/fetch_osm_extracts.py      # 配布ファイルを data/osm/ に落とす（日本全体で約2.9GB）
python3 tools/osm_enrich.py              # 確認するだけ（数を出す）
python3 tools/osm_enrich.py --write      # kb/ に書き戻す
node tools/build_attribution.mjs --write # 出典の一覧（kb/attribution.json）を作り直す
node tools/kb_check.mjs                  # 収録の点検
```

ファイルを指定することもできます（地域ごとの8本など）。

```bash
python3 tools/osm_enrich.py --write hokkaido.osm.pbf tohoku.osm.pbf …
python3 tools/osm_enrich.py --kb kb-private --write   # 別の収録に
```

`data/osm/` は Git に入れません（数GBあり、落とし直せば同じものが手に入ります）。

## かかる時間と結果（2026-11-10、OSM は 2026-11-09 時点）

日本全体（地域ごとの8本、合計約2.7GB）を、4コア・16GB の機械で走らせた結果です。

| | |
|---|---:|
| 走査（8本） | 175秒 |
| 突き合わせ（収録 40,843件 × OSM 273,653件） | 14秒 |
| **合計** | **3分9秒** |

日本全体を1本にまとめたファイル（2.9GB）でも、3分20秒で同じ結果になりました（合った場所 3,879件）。

2回目からは走査の結果を控えから読むので、15秒ほどで終わります（配布ファイルが変われば読み直します）。

| 足した項目 | 件数 |
|---|---:|
| 合った場所 | 3,879（Wikidata の番号で 1,712・名前で 2,167） |
| 営業時間 | 1,214（うち旅程で使える形に読めたもの 1,136） |
| 電話 | 1,573 |
| 公式サイト | 2,756 |
| 車いすの可否 | 504 |
| 車いす用トイレ | 83 |
| 料金の有無 | 734 |

合うのは収録の1割ほどです。残りは、OSM に載っていないのではなく、**足す値（営業時間など）が
OSM に書かれていない**場所です（山・滝・神社の多くは、名前と場所だけが描かれています）。
OSM に無い値を、こちらで作って埋めることはしません。

## 何が入るか

1件ごとに `osmInfo` を足します。**収録のほかの項目には触りません。**

```json
"osmInfo": {
  "ref": "way/123",
  "opening_hours": "Tu-Su 09:30-17:00; Mo off",
  "phone": "+81 75-123-4567",
  "website": "https://example.jp/",
  "wheelchair": "yes",
  "toiletsWheelchair": "yes",
  "fee": "yes",
  "charge": "500 JPY",
  "via": "wikidata",
  "m": 42
}
```

| 項目 | 中身 |
|---|---|
| `ref` | 元の OSM の番号（`node/…`・`way/…`・`relation/…`）。<https://www.openstreetmap.org/way/123> で元を見られます |
| `refs` | 値を足すのに使った、ほかの番号（同じ場所が点と面の両方で描かれているとき） |
| `opening_hours` | OSM の書式のまま |
| `wheelchair` | `yes`・`limited`・`no`・`designated` |
| `via` | どう突き合わせたか（`wikidata`＝番号が同じ／`name`＝名前が同じで近い） |
| `m` | 収録の座標からの距離（m） |

出どころごとに項目を分けてあるので、条件の違うデータが混ざりません（OSM は ODbL、説明文は
CC BY-SA）。まとめて外すときは `osmInfo` を消すだけです。

## どう突き合わせるか

1. **Wikidata の番号が同じ**（収録の id が `wd-Q123`、OSM に `wikidata=Q123`）。名前の表記が
   違っても同じ場所です（OSM の「第75番札所 善通寺」と収録の「善通寺」）。3km 以内なら採ります
2. **名前が同じで、近い**。400m 以内（公園・山・湖・温泉地・スキー場のように広い場所は 1.5km 以内）。
   名前の比べかたは収録の重複判定と同じです（`tools/dedupe_spots.py` の `same_place`）

**同じ名前の別のものは採りません。**

- 駅・停留所・駐車場・トイレ・店・飲食店・宿は、候補から外します。「嵐山」という名前の駅や、
  「東京タワー」という名前の売店は、場所としては別物です（市場や道の駅のように、店そのものを
  行き先として収録している分類では、店も候補にします）
- OSM の側に別の Wikidata の番号が付いていれば、名前が同じでも採りません
- 名前の一部が同じだけ（「西大寺」と「西大寺保育園」）では採りません

おかしな値（電話の欄に「あり」、wheelchair に「unknown」）は捨てます。

## アプリでの使われかた

| 値 | 使いみち |
|---|---|
| 営業時間 | 旅程を組むときの開く時刻・閉まる時刻・定休日・季節の時間（`packages/core/src/osm_hours.js`）。**収録が自分で時間を持っていれば、そちらが勝ちます** |
| 電話・公式サイト | 立ち寄り先の「公式サイト」「電話」のリンク。収録に無いときだけ使います（`js/links.js`） |
| 車いすの可否 | 同行者に車椅子・ベビーカーを選んだとき、分類の目安より先に使います（`packages/core/src/access.js`）。「利用できる」と登録されている場所は選ばれやすく、「利用できない」は後ろへ回ります。旅程にはどちらも、出どころを添えて書きます |

### 営業時間の読み替え

OSM の `opening_hours` は書式がとても広く、ぜんぶは旅程の形に直せません。
**読み切れた書きかただけを使い、1か所でも読めなければ、まるごと使いません**（そのときは、
これまでどおり分類ごとの目安です）。分からない部分だけ飛ばすと、「第3水曜は休み」を落として、
開いていると言ってしまうからです。

| 読める | 例 |
|---|---|
| 毎日同じ時間 | `09:00-17:00`、`24/7` |
| 定休日 | `Tu-Su 09:30-17:00; Mo off`、`Mo-Fr 09:00-17:00`（土日は休み） |
| 曜日で違う時間 | `Mo-Fr 09:00-17:00; Sa,Su 10:00-18:00` |
| 季節で違う時間 | `Apr-Oct 08:30-17:00; Nov-Mar 08:30-16:30` |
| 年末年始などの休み | `Dec 29-Jan 03 off` |
| 冬は閉まる | `Apr-Nov 09:00-17:00`（12〜3月は休みとして扱います） |

| 読まない（目安のまま） | 例 |
|---|---|
| 昼に閉まる | `09:00-12:00,13:00-17:00` |
| 第n曜日・隔週 | `We[3] off`、`week 1-53/2` |
| 日の出・日の入り | `sunrise-sunset` |
| 注記つき | `09:00-17:00 "要予約"` |
| 月と曜日の組み合わせの休み | `Dec-Feb Mo off` |

祝日（`PH`）は暦を持っていないので、時間は読み飛ばし、「祝日は休み」だけを控えます。
旅程の注記には「営業時間は OpenStreetMap の情報です。祝日や臨時の休みは、公式でご確認ください。」と出ます。

## 出典と利用条件

OpenStreetMap のデータは **ODbL 1.0** です。

- **「© OpenStreetMap contributors」の表示が必須です。** [著作権表記のページ](../credits.html)、
  `kb/index.json` の `sources`、`kb/attribution.json` に入れています。消さないでください
- **同じ条件で共有する義務があります**（share-alike）。`osmInfo` を含む `kb/` は ODbL の
  派生データベースにあたります。再配布するときは、その部分を ODbL で共有してください
- 学習データの書き出し（`tools/export_training_data.mjs`）は `osmInfo` を読みません

ライセンスの全文: <https://opendatacommons.org/licenses/odbl/1-0/>

## 更新するとき

OSM は毎日変わります。配布ファイルを落とし直して `--write` を付けて走らせれば、**前回のぶんを
外してから**付け直します（OSM から消えた営業時間が、収録に残り続けることはありません）。
