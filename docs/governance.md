# 運営と支援

旅さきを、商用利用を認めない方針のまま続けていくための決まりです。だれが決めるか、支援をどう受けるか、続けられなくなったらどうするかを書きます。

## 変わらないこと

* **旅さきは商用利用できません**（[PolyForm Noncommercial License 1.0.0](../LICENSE)）。これは、寄付や支援をした人・会社にも同じです。**支援しても、商用利用の許可にはなりません。**
* **商用ライセンスは売りません。** 「お金を払えば会社で使える」形の、別の契約も結びません。
* **有料のサポートはしません。** 早く直す・個別に作る・会社向けに使いかたを教える、などをお金と引き換えに約束しません。
* **広告を載せません。** Web 版・README・文書のどれにも、広告や会社のロゴの枠を置きません。
* 2026-10-27 より前に公開した版は The Unlicense のままです（取り消せません）。これは支援とは関係ありません。

利用者向けの文（README・Web 版・記事・支援のページ）では、「無料で自由に使えます」「だれでも使えます」のような、商用利用もできると読める言いかたをしません。「個人の利用・学習・研究・趣味の改変や、非営利の団体での利用はできます。商用利用はできません」と書きます。

## 決めかた

| 役割 | だれ | すること |
|---|---|---|
| 持ち主（メンテナー） | shitianliang1000-alt（1人） | PR のマージ、版の公開、ライセンス・データの判断、公開サイトと鍵の管理 |
| 参加する人 | だれでも | Issue・PR・スポット情報の訂正 |

* **ふだんのこと**（不具合・小さな機能・データの訂正）は、PR を持ち主が見てマージします。CI（`test`・`e2e`・`docker`）が緑であることが条件です（[CONTRIBUTING.md](../CONTRIBUTING.md)）。
* **大きなこと**（ライセンス・データの出どころ・公開先・API キーの扱い・この文書）は、先に Issue で理由と案を出し、持ち主が決めます。決めたことは Issue に書き残します。
* **レビューの責任**: マージした人（今は持ち主）が、その変更に責任を持ちます。AI が書いたコードや文も、人が読んでからマージします。
* 返事は、なるべく1週間以内にします。個人で運営しているので遅れることがあります。

### メンテナーを増やすとき

続けて良い PR を出している人に、持ち主から声をかけます。目安は、3 か月ほどのあいだに PR が 5 つ以上マージされていて、[行動規範](../CODE_OF_CONDUCT.md) を守っていることです。増やしたときは、この文書の表に名前と担当（たとえば「`kb/` のデータ」）を足します。

公開サイトの鍵（Cloudflare・API キー）は、持ち主だけが持ちます。メンテナーを増やしても、必要になるまで渡しません。

## 支援のしかた（いまの状態: 受けていません）

お金の支援は、まだ受けていません。始めるかどうかは持ち主が決めます（⏸ 判断待ち）。

### 先に確かめること

支援を受けると「旅さきの運営に収入がある」ことになります。次の条件が、それでも守れるかを先に確かめます。

* **外部データの「非商用」の条件。** 国土数値情報の観光資源・文化施設・バス停は非商用の条件です（[data-licenses.md](./data-licenses.md)）。
* **外部サービスの無料の枠の条件。** 天気の Open-Meteo の無料の API は非商用に限られます。ほかのサービスも、無料の枠の条件を読み直します。
* **税の扱い。** 個人で受け取ったお金は、所得として申告が要ることがあります。始める前に税務署か税理士に確かめます。

### 選べるもの

| しかた | 手数料（2026-10-27 に確かめたもの） | 合うか |
|---|---|---|
| 受けない（今のまま） | — | いちばん簡単。費用は持ち主が払う |
| [GitHub Sponsors](https://github.com/sponsors) | 個人からの支援は 0%、組織（会社など）のアカウントからは 6% | **始めるならこれ。** リポジトリと同じ場所で、ボタンは `.github/FUNDING.yml` で出せる。住んでいる地域が対象か、申し込みのときに確かめる |
| Ko-fi などの投げ銭のサービス | サービスと決済ごとに違う | 使えるが、GitHub の外になる |
| [Open Collective](https://opencollective.com/) | 受け入れる団体（ホスト）ごとに違う | **今は合わない。** オープンソース向けのホスト（Open Source Collective）は、OSI などが認めたオープンソースのライセンスを条件にしていて、PolyForm Noncommercial は当たらない |

会社のアカウントから支援を受けることはできます。そのときも、商用利用の許可にはなりません。支援のページに次の1文を必ず書きます。

> 支援はお礼の寄付です。支援しても、旅さきを商用に使う許可にはなりません（ライセンスは PolyForm Noncommercial 1.0.0 のままです）。

支援した人へのお礼は、希望した人の名前を `SUPPORTERS.md`（始めるときに作る）に載せるだけにします。会社のロゴ・リンクの掲載や、優先して直す約束などの特典は付けません。

### 使いみちと報告

支援のお金は、旅さきを動かす費用にだけ使います。

* 公開サイトの費用（Cloudflare の有料の枠、ドメイン）
* AI・経路の API の費用（今は無料の枠の中）
* データの使用料（たとえば経路の API を有料のものに替えるとき、#367）

受け取った額と使った額は、1 年に 1 回、Discussions（無いときは Issue）に短く書きます。費用より多く集まったときは、支援の受け付けを止めるか、使いみちを先に Issue で知らせます。

## 続けられなくなったとき

持ち主が長く手を離すとき・やめるときの手順です。

1. README の先頭に「いまは直していません」と書く
2. 支援を受けていたら、受け付けを止め、そのことを支援した人に知らせる
3. 公開サイトを止めるか決める。止めるときは、Cloudflare Worker と PHP 版を消し、費用がかからないようにする。API キーは、提供元の画面で無効にする
4. リポジトリを「アーカイブ」にする（読めるが、変更はできない状態）

引き継ぐ人がいるときは、Issue で知らせてから、リポジトリの移しかたと鍵の渡しかたを決めます。

* ライセンスは PolyForm Noncommercial のままです。引き継いだ人も、商用利用の許可は出せません
* 鍵そのものは渡さず、引き継ぐ人が自分のアカウントで作り直します
* 持ち主だけが持っているもの: GitHub のリポジトリ、Cloudflare のアカウントと Worker の secret、PHP 版のホスティング（InfinityFree）、AI の API キー

この文書を変えるときは、先に Issue で相談してください。
