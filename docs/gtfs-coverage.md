# GTFS-JP のカバー範囲（全国）

[GTFS データリポジトリ](https://gtfs-data.jp/) に載っている時刻表を全部落として検査し、収録のスポット
（40,843件）のそばに、便のある停留所があるかを数えた結果です（Issue #430。仕組みは [gtfs-pipeline.md](gtfs-pipeline.md)）。

```sh
python3 tools/gtfs_feeds.py fetch            # 一覧の全部を落として検査（2回目からは変わったものだけ。全部で 85MB）
python3 tools/gtfs_feeds.py coverage --md    # この表
```

読みかた:

- 一覧に載っているのは、地方の路線バス・コミュニティバス・路面電車が中心です。**JR・大手私鉄・地下鉄と、都市部の大手バス
  （都営バスなど）はほとんど入っていません**。東京・神奈川・大阪・京都の割合が低いのはこのためで、都市部の交通が
  無いという意味ではありません。都市部は ODPT（鍵が要る）や、駅すぱあとなどの乗り換え API の範囲です
- 時刻表の数が 0 の県（福井・京都・鳥取・広島・山口・愛媛・宮崎）でも割合が 0 にならないのは、となりの県の時刻表の停留所が
  県境のそばにあるためです
- 「便のある」は、有効期間の中で、判定の日から先の最初の水曜に1本以上出る停留所です。デマンド交通（予約して呼ぶ形）は、
  停留所が載っていても便の時刻が無いものが多く、数に入りません
- 都道府県の数は、その県の時刻表として一覧に載っている数です（運行をやめたものは除く）
