# 特殊な旅程

「青春18きっぷで」「寝台列車に乗りたい」「世界遺産を全部回りたい」のような、**行き先ではなく旅の形**を指定する要望を、形ごとの専用の処理で組む仕組みです（Issue #442）。

> 書いた人が言っているのは、行き先ではなく旅の形です。形を読んでから、組みかたを選びます。

中身は [`packages/core/src/special.js`](../packages/core/src/special.js) にあります。

## なぜ専用の処理が要るか

いつもの流れ（`pipeline.js`）は、希望の語に合うスポットを、近い順・知られた順に選びます。旅の形をそのまま渡すと、

* 「寝台」「秘境駅」を説明文に含むスポットは無いので、近場の名所が出る
* 「世界遺産を全部」が、近くの世界遺産 1 つで終わる
* 「県庁所在地を踏破」で、県庁の展望ロビーが 1 つ選ばれる

となります。そこで、まず形を読み取り（`detectSpecial`）、形ごとの処理（ハンドラ）で条件を整えてから旅程にします。

## 形の一覧

| 形 | 当たる書きかた（例） | 処理 |
|---|---|---|
| `longest_ticket` | 最長片道切符・最長往復きっぷ | 経路は専用ソルバー（#431、[longest-ticket.md](./longest-ticket.md)）で出す。使えなければそう言って、全国を回る旅にする |
| `japan_loop` | 日本一周・日本縦断・本州横断 | [`journeys.js`](../packages/core/src/journeys.js) の道すじで組む。日数が足りなければそう言う |
| `cruise` | 船旅・長距離フェリー・クルーズ船 | 出発地に近い乗り場の長距離フェリーを選び、着いた先から組む |
| `seishun18` | 青春18きっぷ・18きっぷ | 普通列車だけ（`transport: "local"`）。使える時期と 3 日・5 日の連続を確かめる |
| `sleeper` | 寝台列車・サンライズ・夜行列車 | サンライズ瀬戸か出雲で、着いた朝（高松・松江）から組む |
| `haisen` | 廃線跡・廃駅・鉄道の遺構 | 届く範囲の収録の廃線跡を、必ず立ち寄るにする |
| `hikyo_station` | 秘境駅 | 書かれた駅か、出発地に近い県の秘境駅と、近くの名所で組む |
| `edges` | 最北端・東西南北の端・四極 | 岬を必ず立ち寄るにする。地方が分かれれば旅を分ける |
| `world_heritage` | 世界遺産を全部・制覇 | 26 件を地方ごとの旅に分け、近い地方から組む |
| `capitals` | 県庁所在地を踏破・47都道府県を制覇 | 47 都市を回る順に並べ、日ごとに区切る（日ごとの予定はここで出す） |

青春18きっぷと寝台列車は、ほかの形と一緒に書かれたら**乗り物の指定**として扱います。「青春18きっぷで日本一周」は形が `japan_loop`、乗り物の指定（`modifiers`）が `seishun18` で、普通列車だけで組みます。

### 誤検出を防ぐ決まり

| 書きかた | 読みかた |
|---|---|
| 京都の世界遺産を見たい | 読まない（「全部」「制覇」が無ければ、ふつうの旅） |
| 横浜でナイトクルーズ・遊覧船・川下り | 読まない（その土地の楽しみかた） |
| 夜行バス・寝台バス | 読まない（列車ではない） |
| 47都道府県の名物を食べたい | 読まない（集めきる旅ではない） |
| 四国一周 | 読まない（四国に絞る、いつもの流れで組める） |
| 東海道五十三次 | 読まない（名のある旅だが、いつもの流れで組める） |

当たるべき書きかたと当たってはいけない書きかたは、[`tests/special.test.js`](../tests/special.test.js) に並べてあります。見つけた取りこぼし・取り違えは、そこに足してから直してください。

## 使いかた

```js
import { createCore } from "./packages/core/index.mjs";

const core = await createCore();
const r = await core.special({ wish: "世界遺産を全部回りたい", from: "東京駅", days: 3 });

r.special.mode;    // "world_heritage"
r.special.status;  // "handled"・"partial"（一部だけ）・"needs_solver"（ソルバー待ち）
r.special.rules;   // その形で守ること（「普通列車だけ」など）
r.special.legs;    // 何回の旅に分けるか（世界遺産・四極・県庁所在地）
r.special.notes;   // 利用者に添える一言
r.itinerary;       // 今回の旅程（いつもの流れで組んだもの）
```

形が読み取れなければ `special` は `null` で、旅程は組みません（`core.plan()` を使ってください）。`core.research()` も、特殊な形ならネットで調べずに `core.special()` へ回します（`research.status === "special"`）。

### 最長片道切符のソルバー

Node.js の `core.special()`・`core.research()` は、何も渡さなくても専用ソルバー（Issue #431）で
JR の路線網から経路を出し、その経路から旅程を組みます。しくみと数字は [longest-ticket.md](./longest-ticket.md) にあります。
全国の網では最長と確かめきれないので、制限時間（5秒）内に見つかったいちばん長い候補を出し、
`route.proven` が `false` になります。

出発駅は、頼みに「○○から」「○○発」と書かれたときだけ決めます（`ticketStart()`）。
書かれていなければ全国でいちばん長い経路で、家の最寄り駅は `origin` として渡すだけです。

ほかのソルバーを使うときは `solvers.longestTicket` で差し替えられます。

```js
const longestTicket = async (kind /* "oneway" | "round" */, { from, origin }) => ({
  route: ["稚内駅", "旭川駅", /* … */, "枕崎駅"], km: 10300, legs: [/* {line, from, to, km} */], proven: false,
});
await core.special({ wish: "最長片道切符で旅したい" }, { solvers: { longestTicket } });
```

ソルバーが無いとき（ブラウザ）・失敗したときは `status: "needs_solver"` で、全国を地方ごとに回る旅として組みます。

## 持っているデータ

| データ | 中身 | 変わったら |
|---|---|---|
| `WORLD_HERITAGE` | 日本の世界遺産 26 件（2024 年の佐渡島の金山まで）と、収録で探す代表の場所 | 登録が増えたら足す |
| `CAPITALS` | 47 の県庁所在地と、その駅（`places.js`） | |
| `FERRIES` | 長距離フェリー 6 航路の乗り場・着く先・かかる時間の目安 | 航路の休止・新設 |
| `SLEEPERS` | 定期の寝台特急（サンライズ瀬戸・出雲） | |
| `HIKYO_STATIONS` | 名の知れた秘境駅 8 駅と、近くの名所 | |
| `EDGES` | 本土の四極と、人が住む島の端 | |

時刻・運賃・運行日は持ちません。変わるものなので「目安」と書き、出かける前に確かめるよう添えます。
