おすすめのモデルコース

地方ごとに、つなげて回れる順路を用意しました。時刻は目安です。旅さきに地名をいくつか書けば、同じ順路をその日の条件で組み直します。

東京を、朝から夜まで

1日関東
  1. 07:00浅草寺人のいない仲見世と、朝の本堂。
  2. 10:00東京スカイツリー町の形を、上から。
  3. 13:00明治神宮森を抜けて、参拝。
  4. 16:30横浜中華街夕方から、食べ歩きと夕食。

電車だけで移動できます。山手線と浅草線で、ほぼ一直線。

京都の朝と、奈良の昼

1日近畿
  1. 06:00清水寺朝の舞台。ここが勝負。
  2. 08:00伏見稲荷大社千本鳥居を、四ツ辻まで。
  3. 11:00東大寺奈良へ移動。大仏。
  4. 14:00奈良公園鹿と、春日大社。

京阪と近鉄でつながります。清水寺から伏見までは電車で20分ほど。

山と湖を、2日で

2日中部
  1. 1日目 06:30河口湖朝の逆さ富士。
  2. 1日目 11:00富士山 五合目車で上がって、空気を。
  3. 2日目 08:00上高地大正池から河童橋へ。
  4. 2日目 14:00松本城黒い天守。

1日目は河口湖泊。2日目は松本経由で、帰りは特急。

海と潮をめぐる

2日中国・四国
  1. 1日目 09:00厳島神社潮の時刻を見て、干潮に。
  2. 1日目 14:00原爆ドーム広島市内へ。資料館も。
  3. 2日目 10:00鳴門海峡渦の時刻に合わせて。
  4. 2日目 15:00金刀比羅宮785段。ご褒美の眺め。

1日目は広島泊。2日目は瀬戸大橋を渡って四国へ。

火山と海を、3日で

3日九州・沖縄
  1. 1日目 09:00太宰府天満宮博多から30分。
  2. 1日目 14:00別府温泉地獄めぐりと、共同浴場。
  3. 2日目 09:00阿蘇山草千里と火口。
  4. 2日目 15:00高千穂峡ボートで滝の下へ。
  5. 3日目 09:00桜島フェリーで渡って、溶岩の道。

移動が長いので、レンタカーがあると楽です。電車とバスでも回れますが、本数が少ない区間があります。

北の自然を、2日で

2日北海道・東北
  1. 1日目 08:30知床五湖高架木道から、湖と山。
  2. 1日目 15:00知床岬クルーズ船でしか見えない岬。
  3. 2日目 09:00摩周湖霧の湖。晴れたら幸運。
  4. 2日目 14:00屈斜路湖摩周湖から近いカルデラ湖。砂湯で足を温めます。

道東は移動が長いので、2日では足りません。3日あれば、釧路・網走まで回れます。

読んでから、組む。
